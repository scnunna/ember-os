Slicer settings (PrusaSlicer)

MaterialPETG if available, otherwise PLA. Black or dark grey.
PETG handles heat better: the board reaches ~46 °C when charging with Wi-Fi on.
Layer height0.20 mm
Perimeters (walls)4
Infill15 %
Perimeter generatorARACHNE — required. Some walls are too thin for "Classic" and won't print.
OrientationUpside down, as the designer printed it (match the 3MF). Gives the cleanest outside surface.
SupportsOrganic / tree supports. Make sure supports don't fill the button holes or screw holes.
BrimOptional. Only if the first layer looks weak.
Scale100 % — do not scale. It must fit real hardware.
Time check: if the slicer estimate is over ~1 h 45 min, please put it on the long-print printer (normal slots are 2 h incl. setup).
Estimate: ~19 g + supports ≈ 25 g → about $3.75 at $0.15/g.

Quick checks before I leave

  • Screw holes, button holes, USB-C and SD-card slots are clear (no support or strings inside)
  • Case sits flat, doesn't rock on the table
  • All button sets collected
